# Mis Visitas

App personal para registrar visitas comerciales sin señal, con Pareto por ciudad y canal, KPIs, comisión y precios.

- La app guarda todo primero en el celular y sincroniza con Google Sheets (Apps Script) cuando hay señal.
- La base de ventas y las visitas **no** están en este repositorio: se cargan dentro del celular (Ajustes).
- `apps-script/Codigo.gs`: servidor gratuito para la hoja de Google Sheets y las fotos en Drive.
